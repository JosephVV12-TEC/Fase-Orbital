## Instrucciones de Compilación

1. Debe Abrir `Fase Orbital.slnx` en Microsoft Visual Studio.
2. Si es necesario, se tienen que restaurar los paquetes NuGet del proyecto. Se requieren `Allegro` 5.2.11.3 y `AllegroDeps` 1.16.0, declarados en `Fase Orbital/packages.config`.
3. Para ejecutar, seleccione la configuración `Debug` y la plataforma `x64`.
4. Ejecuta **Compilar > Compilar solución**.

El proyecto está configurado para C++20 y utiliza el toolset `v145`. También incluye configuraciones `Debug` y `Release` para `Win32` y `x64`.
